How to use

  1. Select a preset or choose any color from the custom palette.
  2. Adjust the preview brightness if needed.
  3. Select Full screen to hide the page controls. Press Escape or tap Exit to return.
  4. For display testing, check for dead pixels, uneven color, and brightness differences.

Banknote note: This page only displays colors. It cannot verify whether a banknote is genuine, reproduce ultraviolet/infrared features, or replace official security checks. A screen's colors also vary by display, settings, and ambient light.
